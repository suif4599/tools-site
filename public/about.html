Site dossier · TOOLS / SELF-HOSTED / CLIENT-ONLY

01 Site

Site

A personal hub of small utilities. Every tool that can run entirely in the browser does run there — conversion, processing and storage happen on your device. The only third-party script is Cloudflare Web Analytics: cookieless, aggregate, and without cross-site tracking.

SELF-HOSTED · CLOUDFLARE WORKERS

02 Auth

Accounts

There is no sign-up. Signing in is optional and only enables cloud persistence for the tools that need it; accounts are issued manually by the site owner.

SIGN-UP: CLOSED · COOKIELESS ANALYTICS

03 UI

Design

Built on the ak-ui design language — system intensity, dark canvas, clipped geometry. Inspired by the Arknights official website; no game assets used. Normative contract: docs/design.md.

AK-UI / SYSTEM / DARK-FIRST
